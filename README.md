# Glass — a tvOS-style home screen for Android TV

Glass replaces the home screen of an Android TV or Fire TV with a tvOS-inspired interface made of
"Liquid Glass" panels. It runs on **Android 7.1 and later**, including older Fire TV devices (Fire OS 6)
where recent launchers won't install.

## Features

- **Home**: greeting, large clock and date; a glass dock of 6 apps; a 6-column grid below.
- **Real logos**: each app's Android TV banner fills its card; otherwise its logo on its own background
  color, or logo + name on white, like a TV banner.
- **tvOS focus**: springy zoom, shadow, 3D tilt toward the move direction, sheen.
- **Organize**: long-press OK → Move (the icon jiggles), Hide, App info.
- **Control Center** (≡ key or the top buttons), sliding in from the right:
  - **Wi-Fi**: status, current network and IP, nearby networks, connecting with a password;
  - **Bluetooth**: paired devices and their status, search, pairing, forgetting (the remote is protected);
  - **animation** speed, **wallpaper**, **Top Shelf**, hidden apps;
  - **System** module: memory, storage, IP;
  - shortcuts to the settings screens the TV lets apps open.
- **Wallpapers**: four abstract styles generated by the app, or your own photo.
- **Languages**: English, French, Spanish, Portuguese (European and Brazilian), German and Turkish, following the device language.
- **Lightweight**: an APK of about 1.8 MB; the blur is computed only once (see below).

## Installation

1. Download the APK from [Releases](../../releases), or build it (see below).
2. On the TV, turn on **ADB debugging** (Developer options).
3. From a computer with `adb`:
   ```bash
   scripts/install.sh <TV IP> path/to/Glass.apk
   ```
   The script installs Glass and grants the optional permissions (Wi-Fi/Bluetooth scanning without a
   permission prompt, custom wallpaper, animation speed).
4. Make Glass your home screen:
   - **Android TV**: press Home and pick Glass, or choose it in
     Settings → Apps → Default apps → Home app;
   - **Fire TV and Google TV**: the stock launcher is protected. Use a Home-button relay such as
     [Launcher Manager Mini](https://forum.xda-developers.com/t/app-firetv-noroot-launcher-manager-change-launcher-without-root.4176349/) on Fire TV, and choose Glass as the launcher.

### Customize
- **Name** in the greeting:
  `adb shell am start -n com.fares.glass/.MainActivity --es name <name>`
- **Custom wallpaper**: `adb push photo.jpg /sdcard/Glass/wallpaper.jpg`, then Control Center → Wallpaper.
- **Different font**: put your files (…Regular, …Medium, …Semibold, …Bold as .ttf/.otf) in
  `/sdcard/Glass/fonts/`. By default, Glass uses Inter.

## Compatibility

| | Android 7 – 9 (Fire OS 6/7) | Android 10 – 12 | Android 13+ |
|---|---|---|---|
| Wi-Fi: list, status | ✅ | ✅ | ✅ |
| Wi-Fi: turn on, connect | ✅ in Glass | system Network screen | system Network screen |
| Bluetooth: devices, pairing | ✅ | ✅ | ✅ |
| Bluetooth: turn on / off | ✅ in Glass | ✅ in Glass | system dialog / settings |
| Animation speed | with `WRITE_SECURE_SETTINGS` (ADB) | same | same |

Settings shortcuts adapt to each TV (`sys/SettingsShortcuts.kt`): for each section, Glass tries the
Fire OS screens, then the Android TV ones, and only shows those an app is allowed to open.
On Fire OS, for example, "Display & Sounds" and "Accessibility" are reserved for Amazon's own apps.

## Building

Requirements: JDK 17 or later (the one bundled with Android Studio works) and the Android SDK (API 36).

```bash
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

The release build is signed with the debug key, for personal use. To publish on a store,
set up your own signing key.

### Translations

UI text lives in `app/src/main/res/values/strings.xml` (English) and `values-fr`, `values-es`, `values-pt`, `values-pt-rBR`, `values-de` and `values-tr`.
To add a language, copy `values/strings.xml` to `values-<code>/strings.xml` and translate it.

## How "Liquid Glass" works without Android 12

Real-time blur (`RenderEffect`) only exists from Android 12, and TV stick GPUs are modest. Since the
background is static, `gfx/Blur.kt` computes a Gaussian blur **only once** (three box-blur passes on an
image scaled down to 480 px, with boosted saturation). Each glass panel (`ui/Glass.kt`) draws the exact
part of that frosted background that sits under it, then a tint, a specular highlight, an inner glow and
a bright rim. The per-frame cost comes down to one `drawImage`.

## Structure

| File | Role |
|---|---|
| `MainActivity.kt` | Home activity, launching apps, permissions |
| `data/AppRepository.kt` | Installed apps, order, hidden apps, preferences |
| `gfx/TileFactory.kt` | Tiles: TV banner › logo on flat color › logo + name |
| `gfx/Blur.kt`, `gfx/Wallpapers.kt` | Gaussian blur, generated wallpapers |
| `sys/WifiController.kt`, `sys/BluetoothController.kt` | Control Center Wi-Fi and Bluetooth |
| `sys/SettingsShortcuts.kt`, `sys/SystemInfo.kt` | Per-TV settings shortcuts, system info |
| `ui/HomeScreen.kt`, `ui/AppTile.kt`, `ui/ControlCenter.kt`, `ui/Glass.kt`, `ui/Overlays.kt` | Interface |
